# AeroMind

Autonomous fixed-wing drone flight AI trained in simulation with deep reinforcement learning (SAC, JSBSim), backed by an aviation knowledge base and a live maneuver milestone dashboard. Designed for future sim-to-real transfer to a physical fixed-wing build.

## Setup

python 3.12 required.

    python3.12 -m venv .venv
    source .venv/bin/activate
    pip install --upgrade pip
    pip install -r requirements.txt
